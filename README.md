# Долбоёбометр — Android MVP

Кроссплатформенное приложение на Flutter: камера, ручной анализ короткого эпизода, демонстрационный результат.

**Важно:** это экспериментальная сборка. Пока нет автоматического распознавания поведения. Приложение не оценивает личность или интеллект по внешности.

APK появится в разделе **Actions → Android APK → Artifacts** после успешного workflow.
